brain-release-lockstep

release integrity
4/4 current installersBrain #77 — split v4.0.3 release identity

Makes Brain's read-only doctor compare the signed bundle, npm package, Stable Spine, Claude plugin, and Codex plugin, and fail health when their resolved versions diverge.

The target patches exact installed npm/npx and persistent Console-runtime installer anchors only. It does not relabel, copy, pin, download, promote, or alter Brain's updater, version store, active.json, host caches, hooks, MCP, or learning runtime. Retirement proof
